# bloggy — Git practice repo

What: dummy project for learning init/add/commit/restore/amend/ignore/rm/mv + remotes.
Why: predict `git status` every step, learn the 3 areas: working dir -> staging -> repo.

How to run:
  cat config.conf   # PORT=4000
  cat .gitignore    # .env, *.log ignored

How to learn with it:
  git log --oneline --graph --all
  git status
